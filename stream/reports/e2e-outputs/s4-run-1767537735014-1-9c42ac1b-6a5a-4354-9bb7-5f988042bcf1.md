## Core Logic Example

Below is a TypeScript code snippet demonstrating a simple `Greeter` class. This class showcases basic object-oriented principles, including interfaces, constructors, methods, and state management.

```typescript
interface GreeterOptions {
  greeting: string;
  target: string;
}

class Greeter {
  private options: GreeterOptions;

  constructor(options: GreeterOptions) {
    this.options = options;
  }

  greet(): string {
    return `${this.options.greeting}, ${this.options.target}!`;
  }

  setTarget(newTarget: string): void {
    this.options.target = newTarget;
  }
}

const myGreeter = new Greeter({ greeting: "Hello", target: "World" });
console.log(myGreeter.greet()); // Outputs: Hello, World!
myGreeter.setTarget("TypeScript");
console.log(myGreeter.greet()); // Outputs: Hello, TypeScript!
```

This example illustrates how to define an interface for configuration, implement a class that uses this configuration, and interact with its methods to change its state and retrieve information.
